# dr-craig

A modern, responsive, and SEO-optimized web application for **Dr. Craig Wright — Homeopath & Phytotherapist** based in Kenilworth, Cape Town.

## 🌿 Overview

This website serves as the clinical platform and digital sanctuary for Dr. Craig Wright's practice, integrating classical homeopathy, full-spectrum botanical phytotherapy, and functional clinical nutrition.

### Key Features
- **Long-Form Clinical Pages**: Deep-dive clinical content for Home, About, Services, Consultations, Insights, AI Wellness Tracker, and Contact.
- **AI Patient Wellness Tracker**: Interactive clinical health monitoring widget built with Recharts, visualizing symptom reduction against botanical remedy adherence.
- **Cape Floral Kingdom Showcase**: Pharmacognosy monographs highlighting indigenous medicinal flora (*Leonotis leonurus*, *Sutherlandia frutescens*, *Pelargonium sidoides*, and *Aloe ferox*).
- **Online Booking & Intake**: Real-time slot selector and preliminary intake form.
- **Medical Aid & Statutory Transparency**: Full AHPCSA registration (`A 08846-HM`) and BHF practice details (`008 000 0356131`) with clear claiming guidance.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts & Data Visualization**: [Recharts](https://recharts.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

---

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
